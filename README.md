# MentorMinute

A per-minute career mentorship platform where Seekers connect with
working professionals (Guides) and pay only for the minutes they use.
Inspired by the Amigzo model.

## Features
- Seeker / Guide registration and JWT login
- Guide search by domain, company and rate
- Live chat session with a per-minute billing timer
- Wallet, transactions and ratings

## Tech Stack
React, Node.js, Express, MongoDB, Socket.io

## Getting Started
1. Clone the repo
   git clone https://github.com/NoTheRaj/mentorminute.git
2. Backend setup
   cd backend
   npm install
   cp .env.example .env
   npm start
3. Frontend setup
   cd frontend
   npm install
   npm start

## API Endpoints
| Method | Endpoint | Description |
|---|---|---|
| POST | /api/auth/register | Register a user |
| POST | /api/auth/login | Log in |
| GET | /api/guides | List guides |
